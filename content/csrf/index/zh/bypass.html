绕过技巧

  • Token 未绑定会话：用自己账号的合法 token 构造攻击页面，受害者提交时 token 依然能通过校验。
  • Token 只校验"是否存在"：提交空 token、删除 token 参数、或传 token=null 试试。
  • 只校验 Referer：用 Referrer-Policy: no-referrer 让请求不带 Referer；或用 https://目标域名@攻击者域名、子域名（目标域名.attacker.com）绕过弱正则校验。
  • SameSite=Lax 限制：GET 型 CSRF 仍然可用；也可寻找站内跳转/开放重定向接口作为"同站第一跳"。
