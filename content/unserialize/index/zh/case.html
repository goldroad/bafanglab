共性规律

  • 入口往往不是显式的 unserialize()：Cookie、自定义请求头（X-XSRF-TOKEN、User-Agent）、Session 读取、maybe_unserialize()、缓存 / 队列、甚至 phar:// 的文件函数都会间接触发。先确认「谁把用户数据喂给了反序列化」。
  • PHP 侧的三个高频魔术方法：__destruct（请求结束必触发，最好用）、__wakeup（反序列化瞬间触发）、__toString（被当字符串用，常接在 file_exists()、字符串拼接之后）；再配合 __call / __get 把「调函数」的权限交出去。
  • 属性可见性决定键名，写错长度整串失效：public 原样、protected 前缀 \0*\0、private 前缀 \0类名\0；需要绕过 __wakeup 时把对象属性个数改大（PHP < 5.6.25 / 7.0.10，CVE-2016-7124）。
  • 传输编码会破坏 payload：放进 Cookie 时 +、= 要 URL 编码（%2B、%3D），放进 URL 参数时 \0 要写成 %00；有些代码会先 strip_tags / stripslashes，就用 \0 和 \\\\ 把它还原回来。
  • 真实环境优先用现成链：phpggc -l 查框架可用 gadget（Laravel / Symfony / Monolog / ThinkPHP / Guzzle…），-b 直接出 base64；找不到链时再按 __destruct → __toString → __call 的顺序手工串。
