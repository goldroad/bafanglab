wfuzz （推荐）

Python 编写的 Web Fuzzer，功能强大、过滤语法灵活。

# 基本用法 - GET 参数名 Fuzz
wfuzz -c -z file,dict_params.txt --sc 200 "?FUZZ=1"

# 过滤技巧 - 按响应行数过滤（排除 131 行的默认页面）
wfuzz -c -z file,dict_params.txt --sh 131 "?FUZZ=1"

# POST 参数 Fuzz
wfuzz -c -z file,dict_params.txt -d "FUZZ=1" --hh 0 ""

本靶场实测：28 条字典，带 --sh 131 过滤后，立即标出 debug (6458 Ch) 和 source (17772 Ch) 两个隐藏参数。

ffuf（替代方案）

Go 编写，速度极快，语法简洁。

ffuf -u "?FUZZ=1" -w dict_params.txt

# 按响应大小过滤
ffuf -u "?FUZZ=1" -w dict_params.txt -fs 6321
