思路提示

参数 Fuzz 的核心是对参数名进行爆破，而不是参数值。本关除了可见的 ?id=1，还藏了 3 个未公开的参数。思路：抓请求后把参数名（如 id）设为 payload 位置，挂上参数字典批量跑，看哪个参数名能触发不同的响应（响应长度变化）。常见隐藏参数名有 debug、admin、source、test、dev 等。

详细解题过程（点击展开）
Burp 玩法：抓 ?id=1 请求 → Send to Intruder → 把参数名 id 设为 payload 位置 → 加载参数字典（debug,admin,source,test,dev...）→ Start attack，看响应长度差异。
ffuf 玩法：
ffuf -u "{{SITE}}/modules/fuzz/index.php?FUZZ=1" -w dict_params.txt
现成字典：本页上方可下载 dict_params.txt，内含本关全部隐藏参数名。
隐藏参数值：debug 参数值为 1，admin 参数值为 true，source 参数值为 1。
响应反馈对照：未带任何已知参数 →「请输入查询条件」；参数名对但值不对（如 ?debug=3、?admin=false）→「找不到对应的数据」；参数名与值都正确 → 返回对应内容。
叠加验证：?id=1&debug=1 会同时返回公开参数提示与 debug 调试信息。
