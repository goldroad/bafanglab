漏洞描述

代码执行指程序把用户输入交给 eval()、assert()、create_function()、反序列化等"代码求值"能力执行。与命令执行不同，它直接在 PHP 进程内执行任意 PHP 代码，可直接写文件、连接数据库、反弹 Shell。

漏洞危害

代码执行与命令执行危害同级且更加灵活：攻击者注入的是 PHP 代码本身，可直接读写数据库、调用任意内部函数、篡改业务逻辑、写入 WebShell；由于代码在 Web 进程内执行，不产生额外的系统调用特征，更难被安全设备检测。此类漏洞一旦出现，通常直接定级为严重（Critical）。

挖掘技巧与经验

  • 找 eval 型入口：在线计算器、模板表达式、规则引擎、preg_replace 的 /e 修饰符（老版本）、反序列化魔术方法。
  • 先执行 phpinfo() 确认环境，再用 system()、shell_exec() 升级为命令执行。
  • 无回显时使用 file_put_contents 写文件，再访问验证。
  • 注意 WAF 对 system、eval 关键字的拦截，可用字符串拼接绕过。
