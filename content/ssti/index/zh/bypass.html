绕过技巧

  • 只过滤了 {{ }}：尝试其它定界符 {$ ... }、<?= ... ?>，或用 }}{{ 闭合再构造。
  • 关键字黑名单（过滤 system / exec）：换用 popen、shell_exec、passthru、proc_open；或用字符串拼接绕过：('sys'.'tem')('id')。
  • 过滤了 PHP 标签：SSTI 不需要 <?php，模板引擎本身就跑在 PHP 里。
  • 沙箱引擎：顺着对象属性链找可利用的方法（如 Twig 的 {{_self.env...}}），或寻找暴露 callable 的 gadget。
  • 延伸练习：PayloadsAllTheThings - SSTI、PortSwigger Web Security Academy - SSTI 专题。
