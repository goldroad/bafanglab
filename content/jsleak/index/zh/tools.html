Burp Suite HAE 插件（推荐）

HAE（Highlighter and Event Log）是 Burp Suite 的开源插件，可自动高亮 API Key、AK/SK、Token、JWT、身份证号等敏感信息。

安装方法：Burp Extender → Extensions → Add → 选择 hae.jar
GitHub：https://github.com/gh0stkey/HaE

HAE 内置 180+ 条正则规则，覆盖：

  • 阿里云 / AWS / 腾讯云 / 华为云 / Azure / GCP AK/SK
  • GitHub / GitLab / Jira / Asana / Slack / Stripe API Token
  • JWT (RS256/HS256)、Base64 编码凭据、URL 编码密码
  • 手机号、身份证号、银行卡号、邮箱、IP 地址

在 Burp 的 HTTP history 和 Repeater 中，匹配到的敏感信息会自动高亮并记录，非常适合本关快速找到 app.js 中的 AK/SK。

Trufflehog 浏览器扩展

由 Truffle Security 开发的 Chrome/Edge 插件，扫描页面加载的所有 JS 文件和 HTML，查找泄露的密钥。

安装：Chrome Web Store 搜索 "Trufflehog"
或：https://github.com/trufflesecurity/trufflehog-chrome

特点：

  • 无需 Burp，浏览器内直接运行，对每个请求自动扫描
  • 覆盖 500+ 种密钥类型（AWS、GCP、Azure、GitHub、Slack 等）
  • 发现后弹出通知，一键复制泄露的密钥

补充工具

  • LinkFinder（Burp 插件）：提取 JS 中的 URL 和 API 端点，顺带找硬编码的密钥。
  • SecretFinder（Burp 插件）：从 JS/响应中提取 API Key、Secret、Token。
  • 手动方案：浏览器 F12 → Sources → 打开 app.js → Ctrl+F 搜 AK/accessKey/secret/LTAI。
