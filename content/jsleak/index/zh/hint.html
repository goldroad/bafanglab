思路提示

前端 JS 中往往硬编码了敏感信息（API 密钥、接口地址等）。思路：打开浏览器 F12 → Sources，找到页面加载的 app.js，全局搜索关键词（如 accessKey、AK、oss），找到云存储的 AccessKeyId 和 AccessKeySecret，填入表单验证即可。

详细解题过程（点击展开）
方法1：浏览器按 F12 → Sources → 找到 app.js，搜索 accessKey。
方法2：Burp Proxy → HTTP history 过滤 .js，右键 Response 查看内容。
方法3：直接访问 /modules/jsleak/assets/app.js，全局搜索 AK 或 oss。
找到的 accessKeyId 与 accessKeySecret 原样填入表单即可。
