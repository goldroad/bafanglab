思路提示

本关考察未授权访问——前端登录页要求登录，但后端数据接口可能没做校验。思路：先从前端 JS 里找到内部接口的路由地址（搜索 API 相关常量），然后换一个无痕窗口（确保没有登录态）直接在地址栏访问那个接口。如果接口直接返回数据，说明未授权。通关凭证就在返回的 JSON 里。

详细解题过程（点击展开）
第 1 步：打开登录页，按 F12 → Network（或 Sources），找到页面加载的前端资源 app.js。
第 2 步：在 app.js 里搜索 API_ROUTES，可以看到内部接口路由：userList = {{BASE}}/modules/jsleak/api/users.php。
第 3 步：换一个无痕窗口（确保没有登录态），直接在地址栏访问：{{SITE}}/modules/jsleak/api/users.php。
第 4 步：接口原样返回 JSON，data 数组第 1 条是 admin，其 remark 字段中就是通关凭证。
Burp 验证：Proxy 抓到该请求 → 右键 Send to Repeater → 删除请求头里的 Cookie → Send，仍然返回 200 与全部数据，说明接口没做任何鉴权。
补充：前台登录永远失败，正是要你意识到"前端登录失败 ≠ 后端接口有校验"，别被登录页挡住。
