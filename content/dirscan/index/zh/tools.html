dirsearch （推荐）

Python 编写，速度快、支持多格式输出、有过滤功能。

# 基本扫描（Kali 自带）
dirsearch -u / -w /usr/share/wordlists/dirb/common.txt -e php,txt,sql,zip,bak

# 使用靶场自带字典（更精准）
dirsearch -u / -w dict_dirs.txt -e php,txt,sql,zip,bak

本靶场实测：48 条字典，25 个线程，1.3 秒扫完，全部目标命中。

dirb

C 编写，Kali 原生自带，速度稍慢但兼容性好。

# 基本用法
dirb / /usr/share/wordlists/dirb/common.txt -X .php

# 使用靶场字典
dirb / dict_dirs.txt -w 3

本靶场实测：common.txt + .php 扩展约 4612 条，约 3 分钟跑完。

补充工具

  • ffuf（Go 编写，速度极快）：ffuf -u "/FUZZ" -w dict_dirs.txt -e .php,.txt,.sql
  • GitHack / git-dumper：扫到 backup/.git/ 后拖下整个仓库还原源码与提交历史。
  • Burp Pro + Active Scan：Burp 自带目录扫描器，适合在抓包过程中顺手扫。

Kali 实战流程

# Kali 虚拟机：192.168.142.162
# 靶场地址：http://192.168.142.1/bafanglab

# 1. 先下载靶场自带字典
curl -s "/includes/dict_download.php?type=dirs" -o dict_dirs.txt

# 2. dirsearch 扫描
dirsearch -u / -w dict_dirs.txt -e php,txt,sql,zip,bak

# 3. 扫到 backup/.git 后，用 git-dumper 拖下仓库
git-dumper /backup/.git/ ./git_dump
cd git_dump && git log --oneline && git show HEAD~1:secret.txt
