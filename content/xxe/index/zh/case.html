共性规律

  • 先找"这个请求是不是 XML"：Content-Type: application/xml、application/soap+xml、multipart 里的 .xml、SVG 上传、DOCX/XLSX 解析、SAML 断言。
  • 有回显：把实体放进一定会被回显的字段（姓名、备注、签名值、LocationConstraint）；无回显：外部 DTD + 参数实体带外（dnslog / 自建 HTTP 服务）。
  • PHP 侧两个开关：LIBXML_NOENT（实体替换）与 libxml_disable_entity_loader(false)（PHP < 8.0）；Java 侧 dom4j parseText()、SAXReader 默认就带 DTD，风险更高。
  • 读含 < 的文件（源码、XML 配置）必须走 CDATA 或 php://filter/convert.base64-encode，否则结构被破坏，只会看到"解析失败"。
