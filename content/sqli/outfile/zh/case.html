场景利用方式结果
某企业官网商品详情页 /product/detail?id=（数字型注入，MySQL 5.7，数据库账号具备 FILE 权限） UNION SELECT ... INTO OUTFILE 向站点根目录写入 shell.php 一句话木马 获取 WebShell，进一步读取数据库配置、横向移动，服务器沦陷
某 CMS 后台统计接口 report.php?type=（未过滤拼接） 先 order by 猜列数，再 UNION SELECT 写入伪装成图片的 .php 文件到 upload 目录 绕过上传点限制，落地可执行脚本，获取管理员权限
某政务系统 /news?id=（MySQL root 账号、secure_file_priv 为空） LOAD_FILE() 读取 config.php 与 MySQL my.ini，配合 HEX() 绕过编码问题 泄露数据库口令、内网地址与文件配置，扩大攻击面
某论坛搜索接口 search.php?keyword=（字符型注入、WAF 仅拦截 union 关键字） 使用 /*!50000union*/ 与十六进制路径绕过 WAF，写入 flag 文件后通过 Web 访问 WAF 规则被绕过，敏感数据被落盘并可直接下载
某在线教育平台作业提交接口（INSERT 注入，返回列数不稳定） 改用 INTO OUTFILE 不依赖回显，把查询结果写入可访问目录后读取 在完全无回显的注入点上完成数据外带与文件落地

以上案例均来自公开漏洞库与授权测试项目的脱敏记录，仅保留漏洞位置与利用方式用于教学。实际防守中，应同时收紧数据库 FILE 权限、secure_file_priv 与 Web 目录执行权限，三者缺一都可能被突破。
