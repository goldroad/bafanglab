修复方法

  • 使用参数化查询（PDO / MySQLi prepared statement），JSON 解析出的字段作为绑定参数传入，禁止字符串拼接。
  • json_decode 后校验 json_last_error()，格式错误直接返回 400，不进入 SQL 逻辑。
  • 对 JSON 字段做类型与白名单校验，例如 id 强制 intval，username 限制字符集为 a-zA-Z0-9_。
  • 生产环境关闭错误回显（display_errors=Off），错误只写服务端日志，对外返回统一提示。
  • WAF 需开启 JSON body 解析与规则匹配，不能只检查 URL 和表单参数。
  • 数据库账号最小权限，禁止业务账号拥有 FILE、DROP 等高危权限。
