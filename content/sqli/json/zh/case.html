位置影响
POST /search（JSON）keywords 参数 云锁 WAF 不检查 JSON body，# 闭合 + EXTRACTVALUE 报错注入，已提取 admin 管理员账号/密码、全库 37 张表结构
POST /c/subject/page orderByField 参数（JSON） ORDER BY 子查询 SLEEP 时间盲注，MySQL，延时与秒数线性对应，sqlmap 复确认，无需 token
POST /biz-config/un_auth/attribute/listDto conditions[].field（JSON） 未授权 extractvalue 报错注入，MySQL 8.0.28，可读同实例全部 22 个租户库：act_id_user 772 用户、企业 PII（公司名/手机/邮箱/信用代码）
POST /api/login（JSON）username 字段 前后端分离项目，JSON body 未过滤，"admin' or '1'='1" 万能密码绕过登录，进入后台后越权读取全部用户数据
POST /user/info（JSON）uid 字段 数字型 JSON 注入，{"uid":1 and sleep(3)} 时间盲注成功，逐字符提取数据库版本与表结构
POST /order/query（JSON）orderNo 字段 字符型 JSON 报错注入，updatexml 带出数据库账号 root@localhost 与 secure_file_priv 路径，具备写文件条件
