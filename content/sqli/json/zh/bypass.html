绕过技巧

  • WAF 不解析 JSON body：直接把 payload 放在 JSON 字符串值里，很多基于关键字的 WAF 完全看不到，是最常见的绕过方式。
  • 过滤单引号：改用双引号闭合（JSON 字符串本身用双引号包裹，SQL 里的值用单引号；若服务端把双引号也拼进 SQL，则用 \" 闭合），或用 char(39)、0x27 生成引号。
  • 过滤 and/or：用 &&、||、大小写 AaNdD、双写 oorr、内联注释 /*!50000or*/。
  • 过滤空格：用 /**/、%09（Tab）、%0a（换行）、括号 () 代替。
  • 过滤注释符：用 or '1'='1 让条件恒真，或用闭合引号后直接堆叠语句。
  • JSON 转义干扰：服务端若对 JSON 值做 stripslashes，可利用 \\ 转义引号制造注入；若不做转义，直接用单引号闭合即可。
  • 数字型 JSON 字段：不带引号直接拼接，如 {"id":1 and (select updatexml(1,concat(0x7e,database()),1))}。
