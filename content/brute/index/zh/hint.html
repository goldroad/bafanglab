思路提示

本关登录口没有任何防护（无验证码、无频率限制、无失败锁定），目标是用弱口令字典爆破出 admin 的密码。思路：随便输个密码抓包，把密码字段设为 payload 位置，挂上字典批量跑，看哪个响应与众不同。工具可选 Burp Intruder 或 hydra。

详细解题过程（点击展开）
目标账号：admin（密码在常见弱口令字典中）
现成字典：本页上方可下载 dict_passwords.txt，正确密码已包含在内。
Burp Intruder 步骤：
1. 随便输个密码登录，抓到 POST 请求 → Send to Intruder
2. 把 password 值设为 payload 位置
3. Payloads 加载密码字典（下载的 dict_passwords.txt）
4. Start attack，响应长度不同（或含"登录成功"）的即为正确密码
hydra：hydra -l admin -P dict_passwords.txt http-post-form "/modules/brute/index.php:username=^USER^&password=^PASS^:S=恭喜你完成本关挑战" -vV
