修复方法

  • 输出编码：按输出上下文使用 htmlspecialchars($v, ENT_QUOTES, 'UTF-8')（HTML）、JS 编码、URL 编码；不要用黑名单替换关键字。
  • 输入过滤与富文本白名单：允许的标签与属性使用白名单解析（如 HTMLPurifier），移除事件属性与 javascript: 伪协议。
  • HttpOnly：会话 cookie 设置 HttpOnly，XSS 无法通过 document.cookie 读取；配合 SameSite 限制跨站携带。
  • CSP：下发 Content-Security-Policy，限制 script-src 为可信域名，禁止 unsafe-inline 与未知外链，从浏览器侧阻断平台托管脚本。
  • 用户内容独立域名：上传的 HTML/SVG/PDF 放到独立域名或对象存储，强制 Content-Disposition: attachment，避免同源执行。
  • 禁止危险文件类型：上传白名单只保留图片等不可执行类型，并校验真实文件内容。

最小修复示例

// 输出时按 HTML 上下文编码
echo htmlspecialchars($nickname, ENT_QUOTES, 'UTF-8');

// 会话 cookie 加 HttpOnly + SameSite
setcookie('SESSIONID', $sid, array(
    'httponly' => true,
    'samesite' => 'Lax',
    'secure'   => true,
));

// 响应头加 CSP（示例：只允许本站与可信 CDN 的脚本）
header("Content-Security-Policy: default-src 'self'; script-src 'self' https://cdn.example.com; object-src 'none'");
